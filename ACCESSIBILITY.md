# Accessibility Statement

AirBridge is dedicated to providing an accessible, usable interface across desktop and mobile browsers.

## Standards and Goals

Our user interface design targets conformance with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.

Key considerations in our implementation:
- **Keyboard Navigation**: Interactive elements including buttons, tabs, modal dialogs, and inputs can be navigated and activated using standard keyboard interactions.
- **Color Contrast**: Text and visual indicators are selected to ensure legible contrast in both dark and light modes.
- **Clear Indicators**: System status, transfer progress, and connection states provide clear textual labels alongside visual status badges.
- **Focus Management**: Modal dialogs and portals manage focus to assist users navigating with assistive technologies.

## Reporting Accessibility Issues

If you encounter accessibility barriers or have recommendations to improve the usability of AirBridge, please open an issue in this repository describing:
- The affected component or page.
- The assistive technology or input device in use.
- The barrier encountered and expected behavior.
